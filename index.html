삼성 인터넷에서 확인된 2,000자 입력 범위에 맞춰 줄였습니다. 기존 0.1.0 북마크는 아래 코드로 주소를 한 번 교체하세요.

① 한 번만 등록

  1. 사용할 브라우저에서 이 페이지를 북마크에 추가합니다.
  2. 북마크 이름을 자동스크롤로 정하고 주소 전체를 방금 복사한 코드로 교체해 저장합니다.
  3. 주소 맨 앞은 javascript:여야 합니다.
복사가 안 되면 직접 선택

② 읽을 페이지에서 북마크 누르기

조작부가 나타나면 ▶로 시작합니다. 같은 읽기 화면의 다음 회차에서는 기존처럼 조작부가 준비됩니다. ×로 닫은 뒤 다시 켤 때도 북마크만 누르면 됩니다.

불러오는 중에는 작은 ‘취소’ 버튼이 나옵니다. 다시 북마크를 눌러도 취소할 수 있습니다. 켜진 조작부가 있을 때 누르면 닫힙니다. 읽을 페이지에서만 실행하고 APK의 자동스크롤은 종료해 두세요.

인터넷 연결과 사용량

시작할 때 버전이 고정된 약58KB 실행 파일 하나를 GitHub Pages에서 받습니다. 브라우저 캐시가 있으면 재사용할 수 있지만 오프라인 실행은 보장하지 않습니다. 실행 후에는 새 로더의 반복 통신이나 자동 업데이트가 없습니다. 스크롤 기능·속도 저장·다음 회차·닫기는 기존 읽기 화면과 같습니다.

자체 요청에 페이지 내용·전체 주소·쿠키를 넣지 않습니다. 다만 일반 다운로드처럼 서버는 IP 등 연결 정보를 받고, 브라우저의 CORS 요청에는 읽는 사이트의 출처(도메인)가 포함될 수 있습니다.

안 되거나 사라졌을 때

네트워크·사이트 보안 정책·파일 확인에 실패하면 안내하고 멈춥니다. 다시 누르기 전 읽을 페이지인지 확인하세요. 탭 전환·페이지 이동 중에는 불러오기를 취소하며 자동 재시도하지 않습니다. 사이트가 외부 실행 코드 읽기나 본문 프레임을 막는 경우에는 사용할 수 없습니다. 파일은 원본 확인값이 맞아야 실행하며 새 버전으로 바꾸려면 북마크 코드를 다시 등록합니다.

모바일 웨일·삼성 인터넷의 실제 동작은 시험이 필요합니다. 공개된 것은 이 안내와 브라우저 실행 파일뿐이며 APK·서명 키·진단 기록은 포함하지 않습니다.
